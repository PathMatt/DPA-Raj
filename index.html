BACKUP · ONLY IF ASKED

How a consult reaches both LISs

Referring lab

Uploads slides from any scanner, with history, gross and clinical images, through a browser. Nothing to install.

HL7 bridge

A synthetic patient ID carries demographics into the consulting LIS by HL7, which issues its own accession.

Round trip

Stain requests and messages stay in the case. The signed report and annotations return to the referring pathologist.

LIS: Epic Beaker · Cerner · LigoLab · NovoPath. Engines: Mirth Connect · Rhapsody.

BACKUP · ONLY IF ASKED

How an AI result reaches the pathologist

Any vendor

Heatmaps, masks, cell counts, scores and PDFs, each model in its own format.

Middleware

Normalizes the output, checks it belongs to this case, and logs model, version, confidence and time.

The pathologist

Sees it in the viewer and pre-filled in the report, then accepts, modifies or overrides it. Every action is logged.

In the viewer today: Mindpeak · Aisencia · Paige, now part of Tempus [confirm list]

BACKUP · ONLY IF ASKED

Before a case enters a shared collection

Permissions per dataset

Each collection carries its own access rules and data-use terms, accepted at every access.

Masked by default

Researchers search masked metadata. Images and permitted fields are released only on approval.

A full audit trail

Digital signatures and system-wide auditability under 21 CFR Part 11.

Data stays home

Institutions keep their own cases and share selectively. Nothing has to be exported to be found.

The same model CHTN runs across Penn, Virginia, Ohio State, Nationwide Children's, Duke and Vanderbilt.
